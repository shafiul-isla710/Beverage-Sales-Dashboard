# Beverage Sales Analysis Dashboard | Power BI
This is a Project. I build this project based on Beverage  sales data. I made a interactive dashboard.

# Project Overview
The Beverage Sales Analysis Dashboard is a data analytics project built using Microsoft Power BI. The main goal of this project is to analyze beverage sales data, understand sales performance, and present meaningful business insights through interactive visualizations.

# Project Objectives
Analyze overall beverage sales performance.
Track total revenue and units sold.
Understand monthly and daily sales trends.
Compare beverage brands by revenue and profit.
Explore sales performance by division and district.
Build an interactive dashboard to support data-driven decisions.

# Tools and Technologies
Microsoft Power BI — Dashboard development and data visualization
Power Query — Data cleaning and transformation
DAX (Data Analysis Expressions) — Measures and KPI calculations
Data Modeling — Relationships between tables

# Dataset Description
The project workbook contains multiple sheets. For this analysis, three tables were used:

Data
Contains beverage sales transactions and sales-related information

Dates
Contains date information, including year, month, and weekday

Cost
Contains beverage brands and production cost per unit

# Data Modeling
Relationships were created to connect the sales data with the supporting tables.

Both relationships use a one-to-many structure, with the Dates and Cost tables on the one side and the Data table on the many side.
This model allows date and beverage brand information to filter the sales data correctly.
